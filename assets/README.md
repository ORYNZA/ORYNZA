## 1. About ORYNZA

ORYNZA is a premium digital wedding invitation brand focused on creating elegant, personalised and memorable digital experiences for Indian weddings.

The brand combines refined wedding stationery aesthetics with modern digital convenience. Its services may include personalised digital invitations, event information pages, wedding invitation links, venue details, RSVP collection, guest attendance tracking and guest coordination.

The visual identity is inspired by premium Indian wedding stationery, understated luxury, botanical illustrations, elegant typography, natural lighting and tactile paper textures.

This folder contains the images, illustrations, invitation mockups and videos used to develop the ORYNZA website and its digital invitation products.

### Brand principles

- Elegant and timeless rather than flashy.
- Premium but approachable.
- Inspired by Indian wedding traditions and contemporary stationery.
- Consistent use of ivory, champagne gold, sage green, blush and charcoal.
- Clear, readable website layouts with generous whitespace.
- Responsive presentation across desktop, tablet and mobile devices.
- Fast-loading images and videos without compromising visual quality.

## 11. Image Formats and Performance

### PNG

Suitable for logos, icons and decorative illustrations when transparency or lossless quality is important.

A PNG is not necessarily transparent simply because it has a `.png` extension. Verify the actual alpha channel before using an asset as a transparent overlay.

### WebP

Suitable for compressed website photographs, backgrounds and invitation previews where supported.

Convert a file to WebP using an actual image conversion tool. Do not simply rename a PNG file to `.webp`.

### MP4

Used for the supplied video assets.

Keep videos reasonably compressed, avoid unnecessary autoplay and provide still-image fallbacks.

### General performance guidelines

- Keep original high-quality files as master copies.
- Optimise copies for website use.
- Use appropriately sized images instead of delivering very large originals to every visitor.
- Lazy-load below-the-fold images.
- Avoid lazy-loading the main hero image if doing so delays the initial visual experience.
- Use descriptive alt text for meaningful images.
- Use empty alt text for purely decorative images.
- Maintain sufficient text contrast over all backgrounds.
- Check the website on desktop and mobile before publishing.

## 12. React + Vite Asset Reference Examples

If the website later uses React and Vite, and the asset library is placed in the project's `public/assets` directory, a gallery image can be referenced like this:

```jsx
<img
  src="/assets/invitation-mockups/design-timeless-ivory-gold.png"
  alt="Ivory wedding invitation with champagne-gold botanical detailing"
/>
```

A hero background can be referenced in CSS:

```css
.hero {
  background-image: url("/assets/backgrounds/orynza-hero-desktop.png");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

These paths are examples. They must match the final website project structure and the actual filenames.

Do not move the existing asset library into another location unless the website project setup requires it.

## 13. Adding New Assets

When adding a new asset:

1. Decide which folder it belongs in.
2. Give it a descriptive, lowercase filename.
3. Use hyphens instead of spaces.
4. Follow the ORYNZA colour palette and visual identity.
5. Record its purpose and intended website section in this README.
6. Verify its file format and dimensions.
7. Check transparency for decorative PNGs.
8. Optimise a website-ready copy if needed.
9. Preserve the original master file.
10. Verify the asset in the actual website layout.

Suggested naming examples:

- `design-floral-ivory.png`
- `backgrounds/orynza-about-background.png`
- `decorative/orynza-gold-divider.png`
- `supporting/orynza-customer-story.png`
- `video/orynza-new-collection.mp4`

Do not rename or replace existing assets without checking whether the website code already references them.
